# 💻 Code&Chill

[🔗 Live Demo](https://code-chill-1.onrender.com/) 

A **real-time collaborative coding platform** built with **React**, **Node.js**, and **Socket.io**, supporting multi-file editing, collaborative drawing, group chat, and instant code synchronization.

---

## 🚀 Features

- ✏️ **Real-Time Collaboration**: Code together with peers instantly using **Socket.io**.
- 🗂️ **Multi-File Editor**: Create, edit, and manage multiple code files in a clean interface.
- 🎨 **Collaborative Whiteboard**: Draw and brainstorm together using **tldraw** with real-time updates.
- 💬 **Group Chat**: In-app chat for real-time discussions during coding sessions.
- 🌈 **Syntax Highlighting & Auto-Detection**: Powered by **CodeMirror**, `langmap`, and `react-syntax-highlighter`.
- 👥 **Presence Tracking**: Know who is online and where they're editing using **TypeScript**.
- 🚦 **Execution Ready** *(optional)*: Run snippets in supported languages (if configured with backend interpreters).
